# Tailwind UI

## Flujo

1. Leer `FE/.ai/rules/tailwind.md`.
2. Priorizar clases Tailwind simples.
3. Usar CSS propio solo si Tailwind vuelve el HTML dificil de mantener.
4. Revisar estados hover, focus, disabled, loading y responsive.
5. Mantener contraste y accesibilidad visual.

## Reglas

- No esconder decisiones visuales en TypeScript.
- No duplicar patrones de estilos sin motivo.
- No usar clases arbitrarias si existe una alternativa clara.
- Evitar templates visualmente cargados por estilos repetidos.
