# Tailwind

## Regla base

Tailwind es la primera opcion para estilos de componentes.

## Reglas

- Usar clases utilitarias claras y consistentes.
- Evitar CSS propio si Tailwind resuelve el caso sin ruido.
- Extraer CSS solo para patrones repetidos, estados complejos o estilos que Tailwind no exprese bien.
- No duplicar estilos similares en muchos componentes.
- Mantener jerarquia visual clara: espaciado, contraste, estados hover/focus y responsive.
- No mezclar decisiones visuales grandes dentro de logica TypeScript.

## Accesibilidad visual

- Mantener foco visible en controles interactivos.
- Evitar contraste bajo.
- No usar solo color para comunicar estado.
